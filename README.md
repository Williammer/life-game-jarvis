# Jarvis · 今日工作台原型

用户选择方向：C 证据工坊 + A 成长图谱。日历、上下文对话和成长证据在同一个工作台完成；原来的 15 个比较视图保留在 `variants.html`。

```sh
cd /tmp/jarvis-agent-day
python3 serve.py
```

打开 http://127.0.0.1:5179/ 。无新增依赖，刷新清空内存中的示例。手机可在可信同一局域网用 `python3 serve.py --bind 0.0.0.0`，访问电脑 IP 的 5179 端口。默认仅本机可访问。

## 建议试玩

1. 点“试一段晨间描述”，或输入“今晚19点到20点家庭聚餐，今天想做AI实验，连续跑了5天，有点累”。查看新增时间块、恢复选择和暂缓事项。
2. 点日历草案中的练习，编辑时段；当前安排保持不变。检查差异后“确认入历”。也可以点空白时间，快速添加固定事项。
3. 选中已入历任务，输入“把这个缩短15分钟”或“把这个移到13:00”。拖动同样生成待确认提案；有冲突时禁止确认。
4. 输入“实验只做了20分钟，还没跑通”，确认部分进展。点“模拟：临时打断”，观察保留证据、只排剩余25分钟的提案。
5. 输入“实验完成了，共享节点累加已经跑通”，确认记录。重复提交不重复加分；再展开证据记录、点“模拟通过能力验收”，观察能力路线变化。
6. 在“成长地图”点能力缺口，再点“围绕这个缺口安排”。查看真实榜样来源、能力清单覆盖和同距离成绩差值；XP 不改变马拉松成绩。

## 这轮实际验证什么

- 对话、点选、草案编辑与日历移动共享当天安排；提案有版本，确认前不写入有效计划。
- 缺关键时间才局部追问，不强制填写完整晨间表单。
- 下一步随待澄清、待确认、待执行、部分完成、缺能力证据等状态变化。
- C 的成果/证据与 A 的能力图结合；健康恢复合法计分，育儿评价自己的投入。
- 分开行动 XP、能力证据、现实结果；重复记录覆盖重算，撤回证据会重算能力。

## 边界

这是可抛弃的规则模拟，不是真实 LLM、BuilderIO runtime 或 Google Calendar 集成。中文时间解析只覆盖示例语法；未理解时会请你补充。背景、精力格、任务时间和核验均为虚拟；3 分钟目标与长期动力尚待本人试玩验证。

缩短任务仅改变投入时段，不降低成果达标标准；未达标可记录部分完成。进展中的分钟数为该任务累计投入；现实原型只有一个示例日与少量固定任务。撤销仅恢复上次日历，不抹掉进展或偏好。默认只排 08:00–22:00，当前模拟时间可由打断场景前移。

正式 Agent Native 接入应替换意图解释/领域分析层，保留冲突、确认、版本和计分约束；UI-only 业务确认不能被普通 Agent action 代替。详见 [官方应用研究](docs/agent-native-patterns.md)。
