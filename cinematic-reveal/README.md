# Cinematic Vice City reveal concept

Responsive, unofficial GTA VI landing-page mockup with smoked-glass information
cards, detail dialogs, and an original synthesized ambient player.

From this directory, run `npm start` and open `http://localhost:3000`.
No dependencies are required. Use `npm run check` for JavaScript syntax checks.
Set `PORT` to use another port.

Artwork is referenced from Rockstar Games' public reveal website and needs an
internet connection. All artwork and trademarks belong to their respective
owners. This concept is not affiliated with Rockstar Games, does not provide a
playable game, and does not accept pre-orders or payments.

No image generation tool was available. The public source artwork differs from
the requested custom wardrobe, black muscle car, and nighttime street scene.
The interface is designed for a 16:9 desktop viewport and adapts to mobile.
