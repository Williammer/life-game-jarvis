# 榜样、个人与领域评估：可选择的呈现机制

2026-10-03。今日／成长原型新增两种模式，模块独立选择；总览、详情与分析提案使用同一份评估。没有新增运行依赖。

## 两种可试玩模式

- **数量／分数**：保留原始成绩／数量／作品证据，并投射到 0–10 分；双方分别显示分数与起步、入门、进阶、熟练、精通、参照达成等级。
- **凡人修炼境界**：相同的分数映射到炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘、渡劫，并细分初期／中期／后期；10 分显示渡劫圆满。境界名称借用《凡人修仙传》，门槛是 Jarvis 自定义设计，不是小说给出的能力量表。

| 分数区间 | 修炼境界 |
| --- | --- |
| 0 ≤ 分数 < 1 | 炼气 |
| 1 ≤ 分数 < 2 | 筑基 |
| 2 ≤ 分数 < 3 | 结丹 |
| 3 ≤ 分数 < 4 | 元婴 |
| 4 ≤ 分数 < 5 | 化神 |
| 5 ≤ 分数 < 6 | 炼虚 |
| 6 ≤ 分数 < 7 | 合体 |
| 7 ≤ 分数 < 8 | 大乘 |
| 8 ≤ 分数 ≤ 10 | 渡劫 |

每个区间三等分对应初期／中期／后期，10 分为圆满。先按 0.1 分精度展示，再按同一数值划分级别，避免显示 10 分却落在未达圆满的级别。

## 评估含义与资料范围

**榜样对照**与**领域目标达成度**分别计算：前者看双方同口径表现；后者沿用模块目标、权重、证据覆盖，不能混作同一个能力分。

数量指标以榜样数量为 10 分，用 `10 × 个人数量 / 榜样数量`；同距离用时以榜样用时为 10 分，用 `10 × 榜样用时 / 个人用时`。显示上限 10。它表达相对表现，不能说 5 分就证明有榜样一半的总体能力。

作品参照按约定能力清单逐项比较，完成比例映射到 10 分。清单是 Jarvis 演示口径，不能冒充官方对作者的评价。比较的任一项未知则暂不定双方差距；领域目标仍可单独显示暂定分与覆盖率。

自选参照仅有名称／链接时，双方分数与境界保持待评估，先核查来源与可比标准。已知零分与未知不同；未知不会变成炼气或零分。

## Bolt 示例

新增 [World Athletics 男子百米纪录](https://worldathletics.org/records/by-discipline/sprints/100-metres/outdoor/men)中的 Usain Bolt 9.58 秒作为公开参照。个人百米成绩初始未知，不从示例马拉松推算。

试玩：成长总览 → 跑步榜样旁讨论 → “改用 Usain Bolt”并确认 → 个人评估旁反馈 → “100米成绩改为 19.16秒”并确认。数量／分数显示本人 5.0 分、Bolt 10.0 分；修炼模式映射为本人炼虚初期、榜样渡劫圆满。原始成绩、差值与来源均保留。

19.16 秒由试玩者输入，是自述样例，不是用户真实个人能力，也不代表训练建议。

## 反馈与重评

个人、榜样、领域目标和评估口径分别有讨论入口。点击“请 Jarvis 重新评估”会携带该模块与当前结果，提出包含已授权背景、指标来源、缺失项、评分与路线的可审阅提案。可以继续纠正、拒绝或确认；新背景使旧提案过期。

同样的证据重评保留原分数。直接要求加分或升级境界不会变成能力证据。模式切换是展示偏好，保留原指标、有效计划、XP 与待确认提案；不同领域可以使用不同模式。

当前仍为本地有限规则模拟，未接真实模型推理。任意领域专业评分与完整上下文理解需沿用现有结构化分析契约接真实 Agent；此轮验证的是评估机制、映射与反馈闭环。
