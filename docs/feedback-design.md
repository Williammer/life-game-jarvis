# Jarvis checkpoint 反馈与协商设计

2026-10-02。承接本轮 AI-native 游戏化升级，按用户最新反馈补齐对象级交互。

## 需求与研究基线

原则：几乎每一个 Jarvis 给建议的内容都要有用户就地反馈入口，特别是榜样设定、gap 分析与规划建议。一次反馈应携带当时对象、判断、依据和版本；持续协商，直到用户确认一份共同认可的当前判断或计划。

首先回读 `agent-native-interaction-patterns.md` 和 `builderio-agent-native.md` 对 Calendar 草案、Content before/after、Slides selection、Tasks shared actions 的源码核查；新的原始资料研究存主仓库 `docs/research/ai-native-feedback-design.md`，已读取其结论与限制：共享选择与新鲜上下文、可审阅修改、人类纠正猜测与明确采用边界，构成本轮实现依据。

## 产品结构

不增加主导航。每个有意义的建议旁放常驻「与 Jarvis 讨论」入口；桌面和手机共用原生 dialog，显示正在讨论什么、当前内容与来源、该处独立历史、针对性的反馈选项和自由输入。关闭后仍在原位置，切换 checkpoint 不串话。

用户回路：选中判断 → 为什么/纠正/替代/补背景 → Jarvis 回应或澄清 → 修订提案与差异 → 继续修改/拒绝/确认 → 同一来源对象更新。解释型交流不强迫确认；“达成一致”表示用户认可有效版本，不代表模型验证了缺失事实。

视觉延续浅蓝、靛紫与领域色。入口以轻量文字和对话符号出现，非 hover-only；只在有语义差异的 checkpoint 分开，不为每个句子制造按钮。原生 modal 保证键盘与辅助技术可以进入、退出、返回焦点。

## 覆盖矩阵

| 对象 | 要携带什么 | 可行修订 |
| --- | --- | --- |
| 榜样设定 | 人物/作品、公开来源、比较范围、当前选择 | 比较已知候选、换参照、补来源、暂不采用 |
| gap 分析 | 当前数值/验收项、目标、差距、来源及未知 | 更正个人基线、指出不可比、保留未知、补证据 |
| 模块目标/现状分项 | 模块意愿、某一指标、评价口径 | 修正目标文字或观测；能力要求不能凭用户想法虚构通过 |
| 近/中/远规划 | 指定阶段、验收和任务、前置与成本 | 减量、换路线、修改阶段成果；时间窗非追平保证 |
| 今日判断/计划 | 容量、固定安排、已确认/草案差异 | 修改预算、优先级、候选任务、时间；先提案后生效 |
| 挑战合约/检查点 | task ID、难度、标准、奖励预算、当前证据 | 最小/标准/进阶选择；缩时不能自动证明完整掌握 |
| 顾问依据/个人背景 | 原文、范围、时间、是否授权 | 更正或补充背景、撤下不适用依据，旧提案过期 |
| 完成评估/复盘 | 自述、模拟验收、XP、实际投入与下一步 | 纠正归因、降档提案、撤回能力验收但保留行动记录 |
| 当前修订提案 | before/after、版本、实际变化 | 继续协商、拒绝、明确确认；最新版本内撤销 |

## 最小实现边界

复用 `propose/accept` 与 `proposeModule/confirmModule`。一个 checkpoint 对话契约即可，无新 Agent 平台。线程保存在原型内存，提案包含 scope、对象、day/module/context 版本及同一业务 patch。UI 负责确认与回滚；计算、证据解锁、冲突与幂等仍由已有确定性规则负责。

本地回复使用可见的有限规则和已研究案例，任意输入会保留并要求澄清，不能假装执行真实专业分析。正式模型用同一对象上下文与 patch 契约替换候选生成。

## 验证

入口覆盖矩阵；榜样替换后 gap 联动；gap 基线修订前后；阶段规划两轮协商；今日减量确认前后；拒绝无有效状态变化；旧提案阻止确认；线程互不串话；撤销版本守卫；自由文本和来源安全；手机无横向溢出；Escape/关闭返回入口焦点。

## 已实施与已知上限

入口已覆盖上述矩阵，统一用 `feedback.js` 和原生 dialog；线程按实际对象标识保存，背景与证据在不同页面讨论也共享记录。固定评分权重与 XP 规则支持解释／偏好反馈，不把权重意见误写为基线数值。本地支持已知／自定义参照、同口径基线更正、目标与阶段文字、容量与挑战档位、个人背景纠正以及能力验收撤回。任意路线、任意时间与专业方法需真实模型；未识别内容保持原状并澄清。

模块目标／阶段文字修订保留具体任务合约与前置证据，界面明确显示这一边界。个人上下文原文修改会使旧提案过期，模拟分析不宣称理解了所有新背景。实现不增加外部连接、依赖或 Agent 平台。
